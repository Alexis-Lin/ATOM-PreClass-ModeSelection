# Flutter 代码实现说明 · Implementation Notes

课前「选择上课模式」的 Flutter 实现。**纯 `flutter/material`，零第三方依赖**，逻辑与 UI 解耦，方便工程师直接二次开发 / 调试。

> 对应设计：`../PRD 课前模式选择.md`、`../Demo UX 交互原型.html`

> ⚠️ **本轮已与原型对齐（未编译验证）**：本仓库环境无 Flutter 工具链，以下同步为结构性实现，工程师本地 `flutter run` 若有编译问题请反馈修正。本轮新增/变更：
> - **视频存储改版（2026-07-22 会议）**：智能模式**强制上云**；课前**移除**「云端/仅存 ATOM」选择与「更改」入口、去掉 `showDataChoiceSheet` 及其邀请/范围/SD 提示；须知底部只留 `_CloudNotice`（只告知 + 隐私协议）。删除 `DataChoice` / `sessionSave` / `saving` / `resetSession`。
> - **存储关闭门槛**：`GateReason.storageOff` — 全局 `saveVideosOn` 关闭时两个智能模式置灰，gate「需要视频存储 · 开启视频存储」（`controller.setSaveVideosOn(true)`）。
> - **Record & Recap**：云端强制开 ⇒ 不再有「需开启保存」分支，恒展示报告/留存说明，CTA 恒为「准备好了」。
> - **额度用尽 gate**（`GateReason.overQuota` + `controller.hasAiQuota`）；gate 按钮=「升级 Pro」（Pro 价格/额度待定）。
> - **拍摄技巧页**：图 → 纯文字 → 无框小节（去掉了卡片框）。
> - **摆放插画** `FramingIllustration`：换成 B 方向侧视场景（`CustomPainter`，标注走 `l.frKnee/l.frDist`），仍为占位。
> - **配色**：`Wm.plus` 改绿（琥珀只留给 Beta 警告）；**ATOM 圆屏**字号放大。

```
lib/

└── workout_mode/                  # ★ 可复用模块

    ├── strings.dart               # ★ 全部中英文案（L）—— 改文案只动这里
    ├── tokens.dart                # 设计 token（颜色/圆角）
    ├── controller.dart            # ★ 全部业务逻辑（ChangeNotifier）
    ├── shared.dart                # 公用小组件（胶囊按钮 / Radio / Plus 标 / Beta 提示 / 弹窗壳）
    ├── preview_settings.dart      # 课程预览页（预览优先入口）+ 设置页（视频存储全局开关）
    ├── phone_sheet.dart           # 模式弹窗 + 模式卡（未选中只标题）+ 门槛/设备列表弹窗
    ├── course_notice.dart         # 「课前须知」底部弹窗 + 拍摄技巧页 + 云端告知（只读）
    └── atom_screens.dart          # ATOM 466×466 圆屏 + 整屏开始前确认
```

**关注点分离**：`controller.dart` 是唯一的规则来源；UI 只读它的判定函数，不自己算逻辑。**所有文案集中在 `strings.dart`（`L`）**（与原型 `T` 一一对应）。

### 结构（方向 F）
具名三选一（Live Coach / Record & Recap / Manual Log）；未选中卡片**只显示标题**，选中才展开一行说明。心智提示 `flexNote`（*「不确定？课中随时能切换，先选一个。」*）为**卡片下方、按钮上方的绿色小字**，**离线时不显示**。

### 完整流程（预览优先）
**课程预览页**（`CoursePreviewPage`，右上角齿轮进 `SettingsPage`）→ 点「开始训练」弹出**模式弹窗** → **AI 模式** 点 CTA → 整页**课前须知**（Live Coach：教练心智副标 + OK 取景图 + 4 条做到 + 「查看拍摄技巧」入口 + Beta；Record & Recap：宽松取景 + 报告/留存）。「拍摄技巧」二级页（`FramingTipsPage`）放教练心智 + OK 图 + 稳定摆放(三脚架) + 反例 + 每个动作差异 → `I'm ready` → `onStart`。**Manual Log** 不走须知直接开始。

### 视频存储（只告知，不给选）
智能模式的报告依赖云端 → 视频**强制上云**。课前**不给存储选择**：须知底部只有 `_CloudNotice`（一行「视频将同步到云端用于生成课后报告，可在 App 回看」+ 隐私协议）。本地 SD 录制是 ATOM 端自己的开关（解耦，App 不接管）。全局隐私开关 `saveVideosOn`（设置页「视频存储」，默认开）**关闭时**：`isLocked` 让两个智能模式置灰、`missing` 追加 `GateReason.storageOff`，gate 引导「开启视频存储」。`aiUsable` 也纳入 `saveVideosOn`（关掉时「课中随时能切」小字隐藏）。

## 3. 核心逻辑（controller.dart）· Source of truth

三个判定函数是整套交互的地基：

| 方法 | 含义 |
|---|---|
| `isLocked(mode)` | 缺前置条件（无设备 / 无 Plus）→ 灰化锁定，点击弹门槛说明 |
| `missing(mode)` | 返回缺哪些（设备优先），驱动门槛弹窗文案与按钮 |
| `canStart(mode)` | 能否真正开始：AI 模式还需 ATOM **在线**（离线无法提供影像 → 拦截）|

规则要点：
- **Live Coach / Record & Recap** 需 `设备 + Plus`；**Manual Log** 永远可用。
- 手机**只判联网**，无「距离」检测 → 只有 `online / noNetwork` 两态。
- 选中项若因状态变化被锁 → `_reconcileSelection()` 自动回退到可用模式；AI 仅离线不算锁定（可选中，但 CTA 拦截）。

## 4. 集成方式 · Integrate

```dart
final controller = WorkoutModeController(
  devices: [AtomDevice(id: 'x', name: 'ATOM 449C', state: AtomConnState.online)],
  isPlus: true,
);

// 手机端：作为底部弹窗
showModalBottomSheet(
  context: context,
  isScrollControlled: true,
  builder: (_) => WorkoutModeSheet(
    controller: controller,
    onStart: (mode) => startWorkout(mode),   // 通过全部确认后触发
    onAddDevice: () => openPairingFlow(),     // 你的配对流程
    onGetPlus: () => openMembershipFlow(),    // 你的会员流程
  ),
);

// ATOM 端：设备屏
AtomRoundScreen(controller: controller, onStart: (mode) => startWorkout(mode));
```

交互内建：锁定卡点击 → 门槛弹窗（缺设备/缺 Plus/额度用尽/视频存储关闭）；AI 模式点 CTA → 课前须知底部弹窗（含云端告知、可「下次不再提示」）；多设备 → 切换图标弹设备列表；ATOM 端 Start → 整屏确认（可「不再显示」）。

controller 记忆：`saveVideosOn`（视频存储/隐私开关）、`skipNotice`（跳过手机端课前须知）、`skipAtomConfirm`。视频强制上云，无存储去向选择。

## 8. 评审记录：鲁棒性 / 边界 / 空状态 · Review notes

一次以「交给前端工程师接力」为目标的自查，已修正/确认如下（方便直接往下开发）：

**已修（鲁棒性）**
- **模式选择弹窗防溢出**：`WorkoutModeSheet` 原本 `mainAxisSize.min` 且无高度上限——小屏或系统大字号下会 overflow。已改为**高度上限 90% 屏高 + 模式列表内部滚动 + CTA 固定在底**，并补 home-indicator 安全区 padding。
- **二级弹窗可滚动**：`showAppSheet(scrollable:true)` 现在真正用 `SingleChildScrollView` 包裹内容；设备列表弹窗改为 `scrollable:true`——多设备 / 大字号不再 overflow。

**已确认（边界 / 空状态）**
- **无设备 / 无 Plus / 额度用尽 / 离线**：分别走「添加设备 / 开通 Plus / 升级 Pro / CTA 置灰」，由 controller 的 `isLocked` / `missing` / `canStart` 统一判定（单一事实源）。
- **门槛多因**：`missing()` 按「先设备、后会员/额度」排序，gate 取第一个，逐步引导。
- **强制解包安全**：`activeDevice!` 仅在 `if(paired)` 分支使用；`activeIndex` 做了 `clamp`。
- **长文本**：设备名、课程名均 `ellipsis`，不撑破行。
- **课程数据为空**：动作清单为空只是渲染空列表，不崩。

**微动效**
- 卡片展开 `AnimatedSize`、按钮 `AnimatedScale`（iOS 式按压、无 ripple）、ATOM 确认页 `AnimatedSwitcher`（淡入+轻微缩放）；参数集中在 `tokens.dart` 的 `WmMotion`；全局 `MediaQuery.disableAnimations` 生效（尊重「减弱动态」）。

**留给工程师注意**
- **ATOM 设备端不硬拦门槛**：`AtomRoundScreen` 的开始不校验 Plus/额度/在线——设备端权限属账号/固件同步，手机是主要把关方（与嵌入式 `Code C ATOM/` 一致）。要设备自拦就在 `onStart` 前加判断。
- **`onStart` 是唯一「前进」出口**：弹窗自身不导航；如整套流程是模态呈现，请在 `onStart` 里先关掉这些 sheet（`Navigator.popUntil`）再跳转训练页。

> 设备端另有 **`../Code C ATOM/`**（LVGL 嵌入式 C 参考实现），页面与本目录 `atom_screens.dart` 一一对应。
